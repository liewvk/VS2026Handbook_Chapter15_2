# VS2026Handbook_Chapter15_2

Visual Studio Handbook Chapter 15 example 15.2.

## Description

This C# console application demonstrates basic file input and output. It creates a `sales.csv` file containing monthly sales data, reads the file back, and prints each row to the console.

## Requirements

- .NET 10 SDK
- Visual Studio 2026 or another compatible C# development environment

## Run the application

From the repository root, run:

```bash
dotnet run
``>

The application writes `sales.csv` to the application's working directory and prints:

```text
Month,Sales
Jan,1200
Feb,1650
Mar,1810
```
